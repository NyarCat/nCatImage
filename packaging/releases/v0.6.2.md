# nCatImage v0.6.2 — 원본 배율, 창 크기 복원, 메타데이터 복사

- 오른쪽 아래 확대·축소 버튼 왼쪽에 현재 배율과 표시 크기를 표시합니다. 메타데이터 패널의 겹친 문서 버튼은 현재 내용을 일반 텍스트로 복사합니다.
- 시작 시 첫 이미지가 창보다 클 때만 화면 작업 영역 안에서 창을 키웁니다. 여유가 있는 방향은 가운데 정렬하고 넘치는 오른쪽·아래는 축소하지 않고 가립니다. 마지막 일반 창 크기는 자동 복원합니다. `9`는 명시적인 전체 맞춤입니다.
- Linux의 Wayland 분수 배율 계산을 고쳤습니다. Windows는 모니터별 DPI 인식을 적용해 OS가 창 전체를 확대하지 않도록 했습니다.
- 우클릭 → **로그 보기**에서 현재 실행의 최근 진단 로그를 확인할 수 있습니다. 로그 파일은 저장하지 않습니다.

## 다운로드 및 검증 범위

- **Linux x64 AppImage:** glibc 2.39 이상.
- **Windows x64 `UNTESTED` EXE:** Windows 10(1703 이상)·11용 미서명 개발 프리뷰. 실제 Windows에서의 이미지 표시, 혼합 DPI/다중 모니터, 입력과 워커 보호는 이번 빌드에서 검증하지 않았습니다. 알려진 네이티브 CI 오류 `private owner/DACL required`는 남아 있으며 보호를 우회하지 않습니다.
- Windows 라이선스 고지, 경고문과 전체 파일의 `SHA256SUMS`를 함께 제공합니다. macOS 빌드는 없습니다.

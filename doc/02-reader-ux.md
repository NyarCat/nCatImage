# 02. 코믹 읽기 UX

아래는 목표 UX다. 현재 M1은 단일 페이지 UI이며 두 장/이어보기/터치 등 전체 완료가 아니다. [실제 상태](08-implementation-status.md)를 함께 확인한다.

Linux·Windows의 플로팅 바는 [ImageViewer](https://github.com/edith2580/ImageViewer)의 화면 배치·가장자리 표시·핀 동작을 참고해 GTK4·Win32에서 독립 구현했다. 원본 소스나 아이콘은 재사용하지 않는다.

## 1. 화면과 기본 흐름

현재 배치는 [읽기 조작과 제목 표시줄](14-reader-control-layout.md)을 따른다. 현재/전체 프레임 수(확인 전 `?`)는 제목에, 재생 상태는 버튼 기호로 표시한다. 일시정지에서 프레임 번호를 입력한 뒤 이동 또는 Enter로 이동하며, 전체 수를 모를 때 범위를 넘기면 마지막 프레임에 머문다. 이전/다음은 프레임 경계에서 버튼을 깜빡이지 않고 중복 요청을 받지 않는다. 정지 이미지에는 애니메이션 조작부를 숨긴다.

```text
상단 중앙: 이전·번호 입력·▾·다음 / 읽기 방향 / 고정

                       페이지

왼쪽 아래: 애니메이션 조작        오른쪽 아래: 확대·맞춤·회전·전체화면·고정
썸네일 줄은 향후 목표이며 미구현.
```

- 첫 실행 제목에 우클릭 열기를 안내한다. 드롭과 열기 단축키를 유지하되 서재·전체 디스크 검색·표지 목록을 만들지 않는다.
- 두 바는 기본 고정이며 개별 고정 해제 후에는 해당 가장자리에서 나타난다. 백틱은 두 바의 고정을 일괄 전환한다. 이미지 배율과 배치는 바의 표시 여부와 독립적이다. 터치 동작은 별도 검증 대상이다.
- F11은 전체화면 전환, 메인 뷰어 Esc는 앱 종료다. 고정·자동 표시 규칙은 일반 창과 전체화면에 같다. 파일/주소 대화상자의 Esc는 취소다. 페이지 전환 효과는 기본 없다. 접근성 검증은 미완료다.
- Windows 및 WSLg에서 실행한 검사와 실제 Linux에서 남은 검증은 [검증 기록](14-reader-control-layout.md#검증)을 따른다.
- Linux는 GTK4, Windows는 Win32 창과 메뉴/대화상자를 사용한다.

## 2. 열기·정렬·탐색

- 파일/폴더/지원 압축을 대화상자·드롭·명령행으로 연다. 다중 드롭은 임의의 첫 항목을 고르지 않고 거부한다. desktop/MIME 통합 전체는 별도 검증 대상이다.
- Ctrl+L/네트워크 버튼에서 SMB·FTP·SFTP URI를 연다. 인증은 OS에 맡기며 비밀번호 포함 URI는 거부한다. 연결 대기 중 입력/종료를 막지 않고 새 선택 뒤 늦은 응답을 적용하지 않는다.
- 개별 이미지 열기는 해당 파일부터 표시하고 부모 폴더의 나열/정렬을 뒤에서 준비한다. 준비 중 이전/다음·전체 번호·검색은 비활성화하고 zoom/닫기는 유지한다.
- 기본은 하위 폴더 제외·파일명 자연순이다. 압축 내부는 전체 상대경로를 기준으로 정렬하며 `__MACOSX/`, `._*`를 기본 제외한다.
- 숫자 부분은 정수 변환 없이 비교한다. 비교 동률은 원시 이름/안정 ID로 결정하고 OS 로캘에 의존하지 않는다. 식별자는 표시용 문자열/소문자 문자열과 분리한다.
- 이름순 역방향을 제공한다. 1.0에서 수정 시각/파일 크기 정렬은 메타가 있는 소스에만 제공한다. 정렬 변경은 현재 항목 ID를 유지한다.
- 파일명 검색은 현재 책의 표시 이름 부분 일치로 제한한다. 검색 결과를 임시 페이지 목록으로 삼고 해제하면 선택 항목을 원래 목록에서 유지한다. 내용/OCR 검색은 없다.
- 번호 이동은 현재 목록의 1-based 번호를 입력한 뒤 `Enter` 또는 `▾`를 누르는 방식이다. 손상/거부된 항목도 번호를 유지한다.
- 뷰어의 `Del`은 현재 일반 이미지를 확인 후 휴지통으로 보낸다. 확인창에서 **다시 묻지 않기**를 체크하고 삭제를 확인해도 앱을 재시작하면 다시 묻는다. ZIP/CBZ 안의 이미지는 삭제할 수 없다.
- 기본 마지막 페이지에서 **멈추고 끝 표시**한다. 자동 첫 페이지 순환/다음 책 자동 열기는 하지 않는다. P1 이전/다음 책은 같은 폴더의 지원 소스 자연순에서 명시적 명령으로 연다.
- 손상 페이지는 짧은 사유·재시도·다음으로 이동을 제공한다. 한 장 실패로 소스 전체를 닫지 않는다.

## 3. 읽기 방향·한/두 장

- 기본 한 장·좌→우. 우→좌는 설정으로 전환하고 기록 허용 시 책별로 저장한다.
- **정렬상 다음 페이지**와 **화면의 왼쪽/오른쪽 입력**을 분리한다. ↓/PageDown/Space는 항상 정렬상 다음, ↑/PageUp/Backspace는 항상 이전이다. ←/→만 읽기 방향에 맞춰 매핑한다.
- 두 장 보기 기본: 표지 단독 켬·가로 이미지 단독 켬. EXIF/사용자 화면 회전 이후 폭>높이면 가로다.
- 정렬 목록을 먼저 spread로 구성한다. 표지 이후 세로 페이지는 두 개씩 묶고 가로 페이지는 단독. 가로 앞 남은 한 장과 마지막 홀수 장은 빈칸을 포함한 한 spread다.
- 예: `표지,P2,P3,가로P4,P5,P6,P7` → `[표지],[P2,P3],[P4],[P5,P6],[P7,빈칸]`.
- 우→좌는 spread 내부의 물리 배치만 뒤집는다. 항목 정렬 자체를 반대로 바꾸지 않는다. 이전/다음은 spread 단위, 번호 이동은 대상 항목을 포함한 spread로 이동한다.
- 방향/표지/정렬/창 크기 변경 시 선택 ID를 포함한 spread를 유지한다. 각 패널의 로딩/오류를 분리하고 한쪽 실패가 다른 쪽 표시를 막지 않는다.
- 두 장의 세부 크기 메타가 미확정이면 잠시 단독 표시 후 같은 선택 ID를 유지하며 확정한다. 작업 결과를 다른 선택에 반영하지 않는다.

## 4. 맞춤·확대·긴 페이지

### 현재 Linux·Windows 동작: 첫 이미지와 창 크기

- 저장된 일반 창 크기로 시작한다. 시작 시 전달된 첫 이미지가 창의 이미지 영역보다 큰 축만 한 번 늘린다. 운영체제나 창 관리자가 허용하는 화면 작업 영역을 넘는 부분은 축소하지 않고 가린다. 빈 창에서 나중에 파일을 열거나 페이지를 넘길 때는 창을 자동으로 늘리지 않는다.
- 기본은 이미지 픽셀 기준 100% 배율이다. 창에 여유가 있는 축은 중앙에 배치하고, 이미지가 창보다 큰 축은 왼쪽·위를 기준으로 오른쪽·아래를 가린다. `9` / 맞춤 버튼은 페이지 전체가 보이도록 줄이는 별도 동작이다. 아주 큰 이미지의 실제 디코딩 해상도에는 기존 메모리·출력 상한이 적용된다.
- GTK 4.12 이상에서는 Wayland의 125% 같은 분수 배율을 그대로 사용한다. 정수 배율만 제공하는 GTK에서는 정수 배율로 계산한다.
- 정상 종료 때 마지막 일반 창의 너비와 높이만 저장한다. 최대화·전체 화면·최소화 상태로 닫으면 직전 일반 창 크기를 사용한다. 창 위치나 열었던 파일은 저장하지 않는다. Linux: `$XDG_STATE_HOME/ncatimage/window-state.json` (기본 `~/.local/state/ncatimage/window-state.json`), Windows: `%LOCALAPPDATA%\nCatImage\window-state.json`.

### 전체 목표

| 모드 | 동작 |
|---|---|
| 전체 맞춤 | 비율 유지·페이지 전체 표시 |
| 폭/높이 맞춤 | 해당 축 기준, 넘는 반대 축은 패닝 |
| 1:1 | 이미지 픽셀과 장치 픽셀 일치, UI 배율과 분리 |
| 작은 이미지 | 기본 확대 안 함, 확대 허용 옵션 제공 |
| 줌 | 5%~1600% UI 범위, 해상도/예산 제한 우선·pointer 위치 유지 지향 |

- 기본 다른 페이지 이동 시 현재 맞춤 모드로 재계산한다. “확대율/위치 유지” 옵션은 정규화된 anchor를 새 페이지 bounds에 clamp해 적용한다. 책 전체 원본 픽셀 좌표를 그대로 복사하지 않는다.
- 확대 입력 중 기존 texture로 즉시 반응하고 정밀 해상도는 뒤에서 갱신한다. 저해상도를 1:1 원본인 것처럼 표시하지 않는다.
- 확대/긴 페이지에는 현재 viewport 위치를 보여 주는 작은 전체 보기 표시를 제공한다. 기존 preview를 재사용하고 이를 위해 추가 원본 decode를 하지 않는다. 사용자가 끌 수 있다.
- 화면 회전은 90도 단위 임시 보기 변환이며 다른 파일로 이동하면 초기화한다. 원본/EXIF를 저장하지 않는다. 색/밝기/선명도 조절은 없다.

### P1 펼침 분할/연속 보기

- 펼침 분할은 한 장 모드에서만 적용한다. 폭>높이인 이미지의 중앙 세로선을 기준으로 가상 반쪽 두 페이지를 만들고 홀수 폭은 오른쪽에 1px 더 배정한다. 좌→우는 왼쪽부터, 우→좌는 오른쪽부터다. 원본 crop 저장은 하지 않는다.
- 두 장 모드에서는 분할을 비활성화하고 이유를 알린다. 분할과 두 장 묶기를 동시에 적용해 페이지 수를 모호하게 만들지 않는다.
- 세로 연속 보기는 정렬 순서를 위→아래로 놓고 폭 맞춤을 기본으로 한다. 좌우 읽기 방향은 수직 순서를 뒤집지 않는다. 기본 한/두 장과 독립 모드다.
- 연속 보기에서는 현재 viewport±한 화면 이내를 후보로 삼고 예산이 부족하면 현재만 유지한다. 화면 밖 전체 페이지의 원본·texture를 보관하지 않는다.
- 미확정 크기는 임시 aspect ratio를 쓰되 확정 후 현재 `항목 ID + 이미지 내 세로 비율` anchor를 유지한다. resize/복원에도 이 anchor를 쓴다. 끝까지 한번에 decode하지 않는다.
- 논리 페이지 ID는 `소스 항목 ID + TIFF 내부 페이지 + 분할 반쪽`이다. 기록은 이 ID/anchor를 저장하고 그때의 번호만 저장하지 않는다.

## 5. 입력

| 입력 | 읽기 화면 동작 |
|---|---|
| Ctrl+O / Ctrl+Shift+O | 파일/압축 / 폴더 열기 |
| Ctrl+L | 네트워크 주소 입력 |
| ↓·Space·PageDown / ↑·Backspace·PageUp | 다음 / 이전 페이지 |
| ← / → | 읽기 방향 기준 물리 이전/다음; 확대 패닝은 drag/휠 사용 |
| Home / End | 첫 / 마지막 |
| 9 | 전체 맞춤; 1:1은 기본 보기, 폭·높이 맞춤 전용 모드는 미구현 |
| + / - | 확대 / 축소 |
| R / Shift+R | 시계 / 반시계 화면 회전 |
| D | 읽기 방향; 두 장 UI는 미구현 |
| 백틱 | 상·하단 바 고정 일괄 전환 |
| F5 | 다시 열기 |
| F11 / Esc | 전체화면 전환 / 메인 뷰어 종료 |
| Ctrl+Q | 종료 |
| Tab·Shift+Tab | 메타데이터 floating layer 토글, 기본 꺼짐. main UI 포커스 이동 없음 |
| Enter | 클릭한 입력 컨트롤 확인/이동 |

- 메인 뷰어의 열기/종료/F11/백틱/Tab은 전역 명령이다. Tab/Shift+Tab 또는 오른쪽 위 `ⓘ`로 메타데이터를 토글한다. 키보드 토글은 포커스를 이동하지 않는다. 기본값은 꺼짐이며 메타데이터가 있는 이미지에서만 패널을 오른쪽에 표시한다. 컨트롤을 클릭하면 Tab 외 native 위젯 입력을 사용한다. 이미지 클릭 후 읽기 입력으로 복귀한다. 모달 주소/파일 선택 창은 자체 표준 입력을 사용한다. 썸네일·검색·도움말 단축키는 아직 구현하지 않았다.
- 일반 페이지 휠은 이전/다음, 확대 시 수직 패닝, Ctrl+휠은 항상 줌, Shift+휠은 수평 패닝이다. “항상 탐색/패닝/줌” 선택도 제공한다. 관성 이벤트 하나마다 페이지를 넘기지 않는다.
- drag는 확대 이미지 패닝. 터치는 화면 좌/우 20% 탭으로 방향에 맞춰 이동, 가운데 60% 탭으로 도구 토글, pinch 줌이다. 이동 거리/시간 threshold를 넘은 swipe만 한 번의 넘김으로 판정하고 pinch/패닝과 중복 실행하지 않는다.
- 터치가 없는 Linux에서도 모든 기능은 키보드/마우스로 가능해야 한다. Android UX 참고는 Android 배포/하드웨어 버튼 연동 약속이 아니다.

## 6. 로딩·기록·접근성

- 선택 이름/번호는 즉시 바꾸고 이전 이미지를 유지하는 동안 즉시 “이전 페이지 표시 중”을 겹친다. 같은 대상 preview가 있으면 우선 재사용한다.
- 150ms 후 계속 대기면 작은 로딩 표시, 500ms가 지나면 이전 페이지를 중립 배경으로 치운다. 오류 시 이전 이미지를 즉시 비워 다른 페이지로 오인하지 않게 한다.
- 같은 항목의 zoom/DPI 업그레이드는 현재 표시를 유지한다. 예산 때문에 먼저 회수하면 중립 화면과 갱신 안내를 사용한다.
- 감상 기록은 첫 읽기 후 한 번 비모달로 opt-in을 제안한다. 기본은 저장 안 함. 허용 전 경로/위치 저장 내용·삭제 방법을 설명한다.
- 허용 시 마지막 **정상 표시된 페이지**/선택 반쪽·anchor·읽기 모드만 debounce 저장하고 정상 종료에도 제한 시간 내 flush한다. 요청만 보낸 미표시 페이지를 이어보기로 기록하지 않는다.
- 파일/컨테이너 리비전이 달라졌으면 저장 ID/이름을 검증하고 자동으로 다른 페이지를 선택하지 않는다. 일치 불확실 시 처음부터/사용자 선택을 안내한다.
- 메뉴/오류/번호/모드에 접근성 이름과 포커스 표시를 제공한다. 매 프레임/미리 읽기는 알리지 않고 선택/오류/완료만 알린다. reduced motion 설정을 존중한다.

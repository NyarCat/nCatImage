# nCatImage v0.6.3 — 페이지 번호 이동과 이미지 휴지통

- 페이지 번호를 입력한 뒤 `Enter` 또는 오른쪽 `▾`로 바로 이동할 수 있습니다. GTK의 중복 `+`·`−` 버튼은 제거했습니다.
- 상단 UI를 숨기면 메타데이터 `ⓘ` 버튼도 숨겨집니다. 이미 열린 패널은 유지되며 `Tab`으로 열고 닫을 수 있습니다.
- 일반 이미지에서 `Del`을 누르면 **“삭제하시겠습니까?”**를 표시합니다. 확인하면 OS 휴지통으로 보내고 다음 이미지(없으면 이전 이미지)를 엽니다. **다시 묻지 않기**는 체크한 상태에서 삭제를 확인한 경우에만 이번 앱 실행 동안 적용됩니다.
- ZIP/CBZ 안에서는 **“압축 파일이라 삭제 불가능합니다”** 경고만 표시합니다. 휴지통을 사용할 수 없으면 영구 삭제하지 않습니다.

## 다운로드 및 검증 범위

- **Linux x64 AppImage:** glibc 2.39 이상.
- **Windows x64 `UNTESTED` EXE:** Windows 10(1703 이상)·11용 미서명 개발 프리뷰. 실제 Windows의 이미지 표시 및 휴지통 이동은 미검증입니다. 알려진 `private owner/DACL required` 오류는 남아 있으며 워커 보호를 우회하지 않습니다.
- Windows 라이선스 고지, 경고문, `SHA256SUMS`를 함께 제공합니다. macOS 빌드는 없습니다.
